| IAM Component          | Architecture Element                | Purpose                                        | Microsoft Entra ID Implementation             | Example in Ability_Enterprise              | Access / Control               |
| ---------------------- | ----------------------------------- | ---------------------------------------------- | --------------------------------------------- | ------------------------------------------ | ------------------------------ |
| **Organization**       | Ability_Enterprise                  | Defines the enterprise IAM environment         | Microsoft Entra ID tenant                     | 500 employees                              | Overall identity boundary      |
| **Identity Platform**  | Microsoft Entra ID                  | Central identity and access platform           | Entra ID tenant                               | Ability_Enterprise tenant                  | Authentication & authorization |
| **Users**              | Users                               | Represents employee and contractor identities  | Entra ID user accounts                        | HR, IT, Finance, Sales, Contractors        | Identity lifecycle             |
| **Departments**        | HR, IT, Finance, Sales, Contractors | Organizes users according to business function | User attributes + security groups             | HR user → HR group                         | Department-based access        |
| **Groups**             | Security Groups                     | Groups users for centralized access management | Entra security groups                         | `GRP-HR-Users`                             | Group-based authorization      |
| **HR Group**           | `GRP-HR-Users`                      | Provides HR-specific access                    | Entra Security Group                          | HR employees                               | HR applications/resources      |
| **IT Group**           | `GRP-IT-Users`                      | Provides IT-specific access                    | Entra Security Group                          | IT employees                               | IT resources/admin functions   |
| **Finance Group**      | `GRP-Finance-Users`                 | Provides Finance-specific access               | Entra Security Group                          | Finance employees                          | Finance applications           |
| **Sales Group**        | `GRP-Sales-Users`                   | Provides Sales-specific access                 | Entra Security Group                          | Sales employees                            | Sales applications             |
| **Contractor Group**   | `GRP-Contractors`                   | Controls contractor access                     | Entra Security Group                          | External contractors                       | Limited business resources     |
| **Group-Based Access** | Group-Based Access                  | Uses group membership to determine access      | Security groups + assignments                 | User added to Finance group                | Automated/centralized access   |
| **RBAC**               | Role-Based Access Control           | Controls administrative permissions            | Entra built-in/custom roles                   | Helpdesk Administrator, User Administrator | Administrative privileges      |
| **Licensing**          | Licensing                           | Controls Microsoft 365/Entra service access    | Direct or group-based licensing               | Business Premium assigned to employees     | Service entitlement            |
| **Applications**       | Applications                        | Controls access to business applications       | Enterprise Applications / App registrations   | HR, Finance, Sales applications            | Application authorization      |
| **Devices**            | Devices                             | Represents corporate endpoints                 | Microsoft Entra device identity               | Corporate Windows 11 device                | Device identity                |
| **Device Identity**    | Device Identity                     | Determines whether a device is known/trusted   | Entra Registered/Joined/Hybrid Joined devices | Corporate laptop                           | Device-aware access            |
| **Authentication**     | User authentication                 | Verifies user identity                         | Passwordless, MFA, FIDO2, etc.                | Employee signs in                          | Authentication                 |
| **Conditional Access** | Access policies                     | Evaluates conditions before granting access    | Entra Conditional Access                      | Require MFA or compliant device            | Risk-based access              |
| **Governance**         | Identity governance                 | Ensures users have appropriate access          | Access Reviews, Access Packages               | Contractor access review                   | Access lifecycle               |
| **Privileged Access**  | Administrative access               | Protects elevated permissions                  | Microsoft Entra PIM                           | IT admin activates role                    | Just-in-time access            |
| **Monitoring**         | IAM monitoring                      | Tracks identity and access activity            | Entra audit/sign-in logs + Log Analytics      | Investigate failed sign-in                 | Detection & auditing           |
