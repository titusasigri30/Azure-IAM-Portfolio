# Microsoft Entra ID & Azure IAM Portfolio

## Overview
This repository documents a hands-on Microsoft Entra ID and Azure IAM
laboratory designed to demonstrate practical identity and access
management skills.

The portfolio uses "Naamalgu Financial Services", to simulate realistic enterprise IAM scenarios.
## Organization
**Naamalugu Financial Services**
- Approximately 500 employees
- IT, HR, Finance, and Sales departments
- External contractors
- Corporate devices
- SaaS applications
- Privileged administrators
- Identity governance requirements

## IAM Capabilities
This portfolio will demonstrate:
- Identity lifecycle management
- Joiner-Mover-Leaver (JML)
- Users and groups
- Role-Based Access Control (RBAC)
- License assignment, modification, and reporting
- Multi-Factor Authentication (MFA)
- Self-Service Password Reset (SSPR)
- Conditional Access
- FIDO2 and phishing-resistant authentication
- Device identity and device-aware access
- Single Sign-On (SSO)
- SAML
- WS-Federation
- OAuth 2.0
- OpenID Connect (OIDC)
- B2B collaboration
- External identities
- Cross-tenant access
- Azure Key Vault
- Managed identities
- Privileged Identity Management (PIM)
- Access packages
- Access reviews
- Sign-in and audit monitoring
- Microsoft Graph PowerShell
- KQL

## Portfolio Approach
Each project follows a practical IAM engineering workflow:
1. Business problem
2. Requirements
3. Architecture
4. Implementation
5. Testing
6. Troubleshooting
7. Security considerations
8. Automation
9. Monitoring
10. Documentation
